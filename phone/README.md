# Подготовка POCO M3 Pro

Это первый шаг: отдельный вход в Telegram на телефоне и проверка доступа
к «Чё там, Чебоксары?». Скрипт не включает сбор новостей или публикации.

Установить основной Termux из F-Droid и выполнить внутри него:

```sh
pkg update -y && pkg install -y python curl
```

Использовать отдельное Python-окружение. Зависимость — только Telethon из
`requirements.txt`; серверные FastAPI и cryptography здесь не нужны.
Программу запускать из внутреннего каталога Termux, не из общей памяти Android.

Ключи приложения вводятся в терминале телефона. Код входа и пароль 2FA
запрашиваются со скрытым вводом. Приложение использует уже созданные ключи
my.telegram.org и создаёт отдельную сессию на телефоне: сессию работающего
Render-сервиса копировать на другой хост не следует.

После проверки программа сохраняет настройки и новую сессию в закрытом
каталоге `~/.local/share/che-tam` с доступом только владельцу. Эти файлы
не предназначены для отправки в чат или загрузки в репозиторий.

Сначала завершить вход и проверить нужный канал. Затем отдельно выбрать
источники, подключить бесплатный ИИ с доступной квотой и включить процесс
с учётом `editorial/style.md`. Для постоянной работы потребуются настройка
фонового режима и автозапуск через Termux:Boot из того же F-Droid.

Проверка на реальном телефоне ещё требуется. На Windows проверяются синтаксис
и изолированные функции; сам вход выполняет владелец в Termux.
