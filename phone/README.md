# Подготовка POCO M3 Pro

Телефон читает открытые Telegram-каналы и сайты из `news.py` и
`telegram_sources.py`, пишет в «Чё там, Чебоксары?» через уже открытую
сессию Termux. `setup.py` нужен только для первого входа.

Установить основной Termux из F-Droid и выполнить внутри него:

```sh
apt update && apt full-upgrade && apt install -y python curl
```

Обновление всех пакетов перед установкой синхронизирует версии системных
библиотек. Если `curl` выдаёт `CANNOT LINK EXECUTABLE`, та же команда обновления
восстанавливает совместимость. Проверить результат можно через `curl --version`.

Использовать отдельное Python-окружение. Зависимость — только Telethon из
`requirements.txt`; серверные FastAPI и cryptography здесь не нужны.
Программу запускать из внутреннего каталога Termux, не из общей памяти Android.

Ключи приложения вводятся в терминале телефона. Код входа и пароль 2FA
запрашиваются со скрытым вводом. Приложение использует уже созданные ключи
my.telegram.org и создаёт отдельную сессию на телефоне: сессию работающего
Render-сервиса копировать на другой хост не следует.

После проверки программа сохраняет настройки и новую сессию в закрытом
каталоге `~/.local/share/che-tam` с доступом только владельцу. Эти файлы
не предназначены для отправки в чат или загрузки в репозиторий.

Если вход уже выполнен, распаковать файлы сборщика в `~/che-tam` и запустить:

```sh
cd ~/che-tam
bash start.sh check
```

Проверка показывает подтверждённый канал, доступ к источникам и пример
поста по свежему сюжету. Ключ OpenRouter берётся из
`~/.local/share/che-tam/openrouter.key`; используется `openrouter/free`.
ИИ видит только выдержки с сайтов. Сборщик пропускает рутинные отчёты и
ищет городские сюжеты с фото или видео. Обычные посты выходят с коротким
заголовком и без отдельной строки с источником. Заголовок открывает
оригинал. Для сайтов и MAX используются публичные превью постов, для
Telegram — доступные для пересылки фото и видео. При недоступном кадре
сохраняется текст новости. Новые подходящие записи Telegram сохраняются
в очередь до следующей публикации, в том числе между перезапусками.
Официальные сообщения и сообщения «Радара ВРВ» обрабатываются отдельно,
даже когда модель недоступна. Их доставка зависит от источников и связи.

Для публикации и просмотра журнала:

```sh
pkg install -y termux-services
bash start.sh start
bash start.sh status
bash start.sh log
```

После обновления файлов выполнить `bash start.sh restart`. Для остановки
сборщика выполнить `bash start.sh stop`. Termux-services перезапускает
процесс после аварийного завершения. Команда `status` показывает процесс,
время последнего сигнала работы, очередь и последние строки журнала.
Проверить доступ к серверу Telegram и ключу OpenRouter можно командой
`.venv/bin/python doctor.py`. Для обычных постов действует интервал 45 минут,
до шести публикаций в сутки с 08:00 до 22:00 по Москве. Тревоги и отбой
проверяются круглосуточно.

Для MAX используется лента мониторинга в бесплатном проекте ТелеМакса.
Добавить в источники проекта `https://max.ru/id2126003194_gos2` и
`https://max.ru/id2128054356_gos`. Для оповещений добавить
`https://max.ru/id2127305504_gos` и `https://max.ru/id2130213317_gos`.
В мониторинге выбрать «В моих источниках» и добавить три правила:

```text
Чебоксары or Чувашия or Чувашская
школа or детсад
БПЛА or беспилотная or ракетная or отбой
```

ТелеМакс передаёт записи, найденные по этим правилам. Срочные сообщения
МЧС и РСЧС о тревоге и отбое выходят со временем и ссылкой на оригинал.
Публикация возможна в течение 12 минут с момента выхода оригинала.
Доставка зависит от частоты обхода источника в ТелеМаксе.

Создать ключ проекта в разделе «Интеграции» и сохранить его на телефоне:

```sh
bash start.sh max-key
```

Ввод ключа скрыт. Сборщик увидит его при следующем опросе ленты.

Установить и один раз открыть [Termux:Boot](https://f-droid.org/packages/com.termux.boot/)
из того же F-Droid. Для автозапуска после перезагрузки выполнить `bash start.sh boot`.
Разрешить автозапуск и работу в фоне у Termux и Termux:Boot в настройках телефона.
