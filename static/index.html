Сохрани подключение

Render Free может останавливать приложение. Чтобы после запуска не вводить код заново, сохрани зашифрованную сессию в настройках хостинга.

Сессия загружена из настроек хостинга и может быть восстановлена после перезапуска.

  1. Открой свой сервис в Render → Environment.
  2. Добавь переменную TG_SESSION_ENCRYPTED со скопированным значением.
  3. Сохрани настройки и дождись нового запуска. Пароль DASHBOARD_PASSWORD сохрани прежним.
Личное подключение через Telegram API.
